Awesome Pixeltable Apps

19 runnable example apps built with Pixeltable, the open-source, Python-native multimodal AI data infrastructure. Each app is a small REST API with tables declared as Python classes, incremental computed columns, UDFs and FastAPIRouter serving. Open one in GitHub Codespaces, run it locally, or deploy it to Pixeltable Cloud.
